# Archived pre-company-v1 lifecycle

These artifacts are preserved as historical design evidence but are not active lifecycle state.
They were moved from the former `.claude/artifacts/` layout into `.aidlc` before the migration was
committed. Consequently, the current paths cannot prove the commits in which their displayed
approvals occurred; several chains also predated strict ordering checks.

Phase 0 archives them instead of fabricating approval history or weakening lifecycle validation.
New delivery work starts in `.aidlc/artifacts/` and uses `accepted` for intent decisions and
`approved` for spec, plan, and review decisions.
