# Ask the graph before you read files

The graph answers exactly five questions. Pick the one you are actually asking — that choice
matters more than anything else here, because asking the wrong one wastes a turn and sends you
reading files anyway.

| You want to know | Command |
|---|---|
| Who would break if I change this | `bash .aidlc/bin/harness graph query callers <symbol>` |
| What this depends on | `bash .aidlc/bin/harness graph query calls <symbol>` |
| Where the load-bearing modules are | `bash .aidlc/bin/harness graph query hubs` |
| Whether the structure has knots | `bash .aidlc/bin/harness graph query cycles` |
| What this change has already touched | `bash .aidlc/bin/harness graph query changed-since HEAD` |

To read code rather than list it, ask for a budgeted pack instead of opening files:

```
bash .aidlc/bin/harness pack "<symbol>"          # ~1200 tokens: definition, callees, callers
bash .aidlc/bin/harness pack "<symbol>" --budget 2500
```

`CODEBASE-MAP.md` at the repository root is the written map: load-bearing modules ranked by what
depends on them, cycles, and where to start. It is generated by `harness map` and capped at 200
lines, so reading all of it is cheap. Read it once at the start of unfamiliar work rather than
opening files to find out what is where.

## Why this beats searching

Measured on this repository's golden queries: 3,397 tokens against 97,995 for the naive file
reads that answer the same questions, at 90% recall. That is the reason the index exists, and
`evals/bench/pack-bench.mjs` fails if either number slips.

## It is a cache, not an authority

The graph is line-oriented, not a compiler. Module imports are reliable; call edges are a good
heuristic filtered against the known symbol table. So:

- **A miss means grep, not "it does not exist."** The commands say so when they miss; believe them.
- **Never conclude nothing calls something from the graph alone.** Confirm a negative with grep.
- **A `STALE since` banner means the last refresh failed.** Verify anything load-bearing against
  the source before you rely on it.
- **`map-drift` in the Stop output means `CODEBASE-MAP.md` no longer describes the tree.** Run
  `harness map` and commit it. A map that has quietly stopped being true is worse than none: for
  eleven days this index answered `renderWiki` from a file that had been deleted.

## Do not

- Read `.aidlc/state/graph.json` directly. It is a cache format and it will change.
- Rebuild the graph by hand mid-task — the `Stop` hook coalesces edits and refreshes once.
