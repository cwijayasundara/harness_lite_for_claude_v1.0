# Spec: compare-native-claude

### B1
The existing eval CLI runs sequential native/harness, graph/no-graph and strong/economical plus
strong evaluation comparisons, with explicit models, matching product requirements and private
acceptance. Native has ordinary instructions, rg, bounded reads and public tests without an
installed harness. Both configurations retain process isolation and external simulated decisions.
### B2
Every scheduled smoke and paired attempt is retained, including failed, incomplete, unaffordable
and unmeasured attempts. Actual model usage, versions, revisions, retries, regressions, approval
violations, cost, latency and available token/cache counts remain inspectable. Unclassified
unnecessary questions and missing billing are unknown. No model substitution is permitted.
### B3
One smoke per configuration and campaign calibrates the initial three paired repetitions under
a finite suite cap. Unknown billing reserves the full allowance; failed calibration or an
unaffordable projection prevents repeated spending and records unmeasured outcomes.
### B4
Graph navigation detects source-content and path changes outside edit hooks, including shell
writes, renames and branch changes. The retrieval benchmark validates golden symbols and
compares against bounded rg reads while retaining historical whole-file numbers as context.

## Safeguards
No new production skills, agents, hook bindings or control budgets. Temporary graph suppression
is an experimental staged-plugin alteration; graph assistance is fresh parent-generated bounded
context. Simulated approval measures the protocol, not arbitrary human judgment. Three pairs
are a small sample, not a universal reliability estimate. Item 5 pruning is deferred.
