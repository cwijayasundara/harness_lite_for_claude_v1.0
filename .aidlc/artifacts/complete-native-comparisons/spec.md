# Spec: complete-native-comparisons

### B1
An optional comparison selector runs one existing native, graph or generation pair with its
ordinary calibration, paired repetitions, model identity, grading, budget and evidence rules.
Unknown selectors and combining the selector with pruning are refused before model invocation.
The default matrix and production controls remain unchanged.
### B2
Complete and report the planned bounded comparisons using the committed campaign driver.
Preserve earlier failures, unmeasured schedules and unknown billing. Keep retries identifiable;
never count an incomplete response as a successful product outcome. Report cost per accepted
change, recovery, approval outcomes, latency and limitations without a universal reliability claim.
