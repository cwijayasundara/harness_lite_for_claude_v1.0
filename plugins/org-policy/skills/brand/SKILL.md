# Brand

Replace this example with the brand owner's source of truth before treating it as binding.

1. Product name is never abbreviated in the first mention on a screen.
2. Error copy is a sentence the user can act on, not an internal code.
3. Do not invent a colour system in the spec — point at `.claude/artifacts/design/<slug>/`.

Flag contradictions under **Policy concerns flagged** in `spec.md`.
