# Spec: correct-existing-mechanisms

## Outcome
Dependable existing mechanisms, with measured integration evidence and honest limitations.

### B1
Configured sensor execution and parsing errors prevent successful verification. Optional absent capabilities remain skipped.
### B2
The evaluator receives explicit base/candidate commits, has only read tools, and returns findings saved by the caller. Independent runtime tests run outside it.
### B3
External test-driver decisions bind full artifact revisions; new plans bind their spec digest. Missing, rejected, forged or stale receipts prevent implementation launch.
### B4
No environment flag permits agent self-approval or forces a pending human-gate turn to continue. The actual installed Claude plugin pauses, accepts a correction and resumes after externally supplied simulated approvals.
### B5
The published workflow executes deterministic tests and cost checks. Optional hosted model execution requires explicit credentials and cannot quietly pass without them. The shipped plugin references existing agents and current hooks.
### B6
Full-run selection and absolute outcomes are truthful. Suite budgets reach the invoker and failed campaigns retain approvals and spend.
### B7
Guidance accurately describes cache reloads, heuristic test presence and local approval metadata. No new production skills, roles or hook bindings are added.

## Boundaries
This change does not claim complete product-campaign success or OS isolation for arbitrary-shell agents.
Local digest metadata is an audit record, not authenticated human identity.
